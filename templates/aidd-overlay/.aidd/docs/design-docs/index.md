# Design Documents

This directory stores long-lived design knowledge for the local overlay.

## Documents

- `core-beliefs.md`: basic beliefs for agent-first development.
- `repo-topology.md`: how the overlay relates to an existing repository.
- `../WORKFLOW.md`: local AIDD workflow.
- `../CI.md`: validation and CI notes.

## Rules

- Record decisions that affect multiple areas here or in ADRs.
- Keep documents concise and link to related task notes, plans, or code.
- Mark obsolete documents instead of leaving stale guidance unlabelled.
